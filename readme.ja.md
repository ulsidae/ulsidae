# 🍯 モットー

```text
Je suis tombé, et pourtant je cours.
```

> [*七転び八起き。*](https://github.com/ulsidae/dev_logs/blob/main/AI/EVO-1/curriculum_neuroevolution.py)

これまで数え切れないほどの挫折を経験してきました。そうした経験がなければ、今の自分はなかったと思います。

だからこそ、これまでの歩みをここに記録してきました。失敗も、挫折も、そして未完に終わった試みも、その一つひとつを大切に残しています。それらは単なる過去の痕跡ではなく、幾度もの困難を乗り越えながらも、前へ進み続けてきた証です。

# 👤 自己紹介

現在、**ソフトウェア開発者**として働いております。主にソフトウェアエンジニアリングに携わるとともに、情報セキュリティや人工知能の要素を取り入れた実用的なシステムの設計・開発にも取り組んでおります。

具体的な成果を重視しており、完成したプロジェクトだけでなく、エンジニアリング上の意思決定を記録することや、失敗や未完の実験から得られた知見を蓄積することも大切にしております。

## 🧭 主なプロジェクト

🎯 **主な関心領域：** ソフトウェアエンジニアリング、情報セキュリティ、人工知能の各分野に関心を持ち、システムの設計・構築・改善に取り組んでおります。

| プロジェクト | 概要 |
|---|---|
| 🧠 [AURIX](https://github.com/ulsidae/AURIX-for-Rust) | 個人向けAIが日常のスケジュール管理やタスク管理を担うとしたら、どのような可能性があるでしょうか。本プロジェクトでは、軽量なAI支援型パーソナル生産性システムの実用性を検証するとともに、事業としての成立可能性についても検討しております。 |
| 📓 [Development Logs](https://github.com/ulsidae/dev_logs) | 個人的な実験や技術的な探究に加え、開発過程で直面した実践的な課題や、その解決に向けた取り組みを記録しております。 |
| 🍯 [RSVP Systems](https://github.com/ulsidae/RSVP-systems) | 日常のさまざまな場面にシステム思考を応用することを試みるプロジェクトです。意思決定の過程、学生自治会での活動、その他の組織運営に関する経験などを記録しております。 |

---

各プロジェクトの概要や着想、ならびにその背景にあるコンセプトについては、[プロジェクトカテゴリ一覧（Project Categories Overview）]()をご覧ください。

また、これまでの取り組みをより幅広くご覧いただくには、[すべてのリポジトリ](https://github.com/ulsidae?tab=repositories)もあわせてご覧ください。
